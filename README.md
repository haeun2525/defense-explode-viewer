# 군 장비 분해 뷰어 — 손짓으로 장비 속을 들여다본다

웹캠 앞에서 손을 펴면 장비가 분해되고, 검지로 가리키면 그 부품이 무슨 일을 하는지 알려 준다.
주먹을 흔들면 장비가 **어떻게 작동하는지** 신호가 흐르는 순서대로 보여 준다.

배회탄약 · 정찰 쿼드콥터 · 야간투시경 · 무인 지상 감시 센서 · 소총, 5종.

```
크롬 웹페이지
 ├ 웹캠 영상 → MediaPipe Hand Landmarker (손가락 21점, 3D)
 ├ 손 모양 판정: 펴기 / 주먹 / 검지 / 양손 / 주먹 흔들기
 └ three.js 로 분해 장면 → 부품 이름 · 칩 이름표 · 작동 보기
```

**웹캠 영상은 브라우저 밖으로 나가지 않는다.** 손 인식은 전부 내 컴퓨터 안에서 돈다.

**카메라 없이도 된다.** 마우스 드래그로 돌리고, 휠로 분해하고, 부품을 클릭하면 된다.

→ **https://defense-explode-viewer.vercel.app** (설치 없이 바로. 크롬 권장 · 웹캠 허용)

> ⚠️ **공개 자료 기반 개념도다.** 부품의 배치·크기·모양과 칩 이름표는 설명을 위한 예시이며,
> 실제 제품의 설계·부품과 다를 수 있다. 부품 설명과 작동 단계 문구는 공개 자료와 대조해 확인했고,
> 판정표와 근거 링크는 [`factcheck/`](factcheck/README.md) 에 있다.

## 손으로 하는 법

| 손 | 하는 일 |
|---|---|
| 손 펴고 움직이기 | 장비가 따라 돈다 |
| 손바닥을 **0.4초** 편 채로 | 편 만큼 분해 (오므려도 그대로 유지된다) |
| 주먹 **0.5초** 가만히 | 조립 (부품 보기 중이면 전체 보기로) |
| **검지**로 가리켜 잠깐 머물기 | 그 부품만 보기 — 이름과 설명, 기판이면 칩마다 이름표 |
| **양손** 벌리기 · 모으기 | 확대 · 축소 (최대 약 6.7배) |
| **주먹을 좌우로 흔들기** (3번 꺾기) | 작동 보기 켜기 · 끄기 |

## 키보드 · 마우스

| 키 | 하는 일 |
|---|---|
| `1`–`5`, `←` `→` | 장비 바꾸기 |
| `S` | 작동 보기 |
| `+` `−` `0` · 트랙패드 핀치 | 확대 · 축소 · 원래대로 |
| `Esc` | 부품 보기 · 작동 보기 나가기 |
| `L` / `C` / `H` | 라벨 / 카메라 미리보기 / 도움말 숨기기 (촬영할 때) |
| `Space` | 자동 시연 |
| 드래그 · 휠 · 클릭 | 회전 · 분해 · 부품 보기 |

주소 끝에 `?debug` 를 붙이면 손 인식 수치(펼침 정도, 검지/나머지)가 화면 위에 뜬다. 손에 잘 안 맞으면 이걸 보며 맞춘다.

## 작동 보기

조립된 채 겉이 반투명해지고, 단계마다 관련 부품이 빛나며 부품 사이로 신호가 흐른다.

| 장비 | 흐름 |
|---|---|
| 소총 | 조준 LED → 방아쇠 → 탄두 발사("탕!") → 가스가 피스톤을 밂 → 노리쇠 후퇴·탄피 배출 → 다음 탄 장전 |
| 배회탄약 | 발사관 대기 → 날개 전개 → 모터·프로펠러 → 비행제어 → 영상 송신 → 목표 지정 → 공격 취소 가능·탄두 작동 |
| 쿼드콥터 | 배터리 → 배전 → 비행 컨트롤러 → 모터 4개 → GPS·항법 카메라 → 경로 계획 → 짐벌 카메라 → 영상 송신 |
| 야간투시경 | 전원 → 고전압 → 별빛이 렌즈를 지남 → 광음극·마이크로채널판 → 형광 스크린 → 콜리메이터 → 적외선 조명 |
| 감시 센서 | 태양광 충전 → 저전력 대기 → 땅 떨림을 지오폰이 감지 → 적외선·소리 → 판별 → 메시 무전으로 경보 |

## 파일

| 경로 | 내용 |
|---|---|
| `web/index.html` | 뷰어 전부 (손 인식 · 분해 · 라벨 · 작동 보기). 외부는 three.js · MediaPipe 만 CDN 으로 |
| `web/models/*.js` | 장비 모델 (glb 를 base64 로 담은 스크립트 — 서버 없이 `file://` 로도 열린다) |
| `products/*.py` | Blender 로 장비 모델을 만드는 스크립트 (부품 이름 · 설명 · 칩 이름표 포함) |
| `lib/explode_common.py` | 공통: 재질, 기판·칩 모양(`bm_pcb`), 분해 메타데이터 |
| `tools/export_web.py` | `.blend` → `web/models/*.js` |
| `tools/webshot.mjs` | 헤드리스 크롬 검사 (화면 캡처 · 가짜 손 판정 · 부품 보기 · 작동 보기) |
| `factcheck/` | 사실 확인 판정표 · 근거 URL · 영상에서 말하면 안 되는 것 |

## 모델 다시 만들기 (Blender 4.x)

```bash
B=/Applications/Blender.app/Contents/MacOS/Blender
$B -b --factory-startup --python products/quad.py -- --look armory      # out/quad_armory/quad_armory.blend
$B -b --python tools/export_web.py -- quad                                # → web/models/quad.js
```

## 검사

```bash
node tools/webshot.mjs                          # 5종 × 분해 0 / 50 / 100% → out/web/
HANDS=1 node tools/webshot.mjs quad             # 가짜 손 좌표로 판정 검사
FOCUS="quad:비행 컨트롤러" FOCUS_ZOOM=2 node tools/webshot.mjs quad   # 부품 보기
SIM=k2c1 node tools/webshot.mjs k2c1            # 작동 보기 단계별
```
