## 공통 원칙 (영상 자막·내레이션)
- 부품 **배치·크기·모양·칩**은 전부 설명용 개념도다. "실제 ○○ 안에 이게 들어 있다"고 말하지 않는다.
  화면에는 "공개 자료 기반 개념도 · 실제 설계·부품 배치와 다를 수 있음"이 항상 떠 있다.
- 칩 이름표의 제품 계열(STM32, Jetson, ARM Cortex-M 등)은 **예시**다 — 이름표에 "예:"로 표시돼 있다.
- 무기의 격발·탄두 관련은 공개된 개념 수준만 다룬다.
- 확인된 사실도 출처는 각 파일의 근거 URL 이다. 백과사전(위키·나무위키)만 근거인 항목은 영상 전에 한 번 더 보는 게 안전하다.

## 반영 위치
- 부품·칩 문구: products/<장비>.py → web/models/<장비>.js 다시 내보냄
