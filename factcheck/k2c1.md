## 영상에서 말하면 안 되는 것
- 조준경 모델의 모양·회로·칩이 **PVS-11K(또는 특정 실제 조준경)의 실제 내부**라고 말하는 것 — 방사청 공동개발품이라 상세 제원이 공개되지 않았다.
- 조준경 전지 종류(CR2032 등)·밝기 단계 수를 단정하는 것 — 공개 자료끼리 엇갈린다.
- '움직임을 감지해 자동으로 켜진다'를 K2C1 조준경 기능으로 소개하는 것.
- 조정간을 '안전·단발·연발' 세 가지로 말하는 것 — 3점사가 있다.
- 개머리판이 '오른쪽으로만' 접힌다고 단정하는 것 — 기본형은 우측, 일부 개량형은 좌측으로 알려져 있다.
- 모델의 치수(전장 0.97m 등)를 실제 제원처럼 말하는 것 — 실제 K2C1 전장은 펼침 1,014mm / 줄임 940mm / 접음 730mm 로 알려져 있다(Wikipedia/Modern Firearms).
- 격발 장치(공이치기·멈치 등)의 세부 구조·치수 — 개념도 수준만 다룬다.
